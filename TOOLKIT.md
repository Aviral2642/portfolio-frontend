# Tools that actually contributed

No skills, MCP servers or runtime packages were installed for this redesign.

- Existing Impeccable guidance: coherent full-page art direction, bounded visual
  inspection and independent review. User-pinned purple/oversize brief wins defaults.
- Existing GSAP React/ScrollTrigger guidance: scoped lifecycle, native scrolling,
  transform ownership, short pin, responsive/reduced-motion matchMedia.
- Existing React 18 / GSAP runtime: production page compiled and browser executed.
- Browser/Playwright: real Chromium screenshots, scrolling, focus, anchors, mobile,
  reduced motion, video and requestAnimationFrame interval observations.
- WebGL2: custom fluid pointer enhancement based on the user-selected technique.
- Jest/React DOM: mocked contact success, loading, duplicate-submit, error/timeout.

Framer Motion stays available to legacy components. No competing timeline system,
new UI kit, new shader package, modeling service or paid tool was added. R3F/Three
are no longer imported by the homepage; legacy original files/dependencies remain
outside the shipped homepage bundle.
